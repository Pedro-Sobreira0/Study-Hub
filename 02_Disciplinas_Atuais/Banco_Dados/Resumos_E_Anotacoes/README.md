# Resumos e Anotações — Banco de Dados

Esta pasta reúne os resumos, as anotações e os materiais de estudo da disciplina de Banco de Dados.

## Objetivo

Organizar os conceitos estudados sobre armazenamento, organização e gerenciamento de dados.

## Conteúdo

- Modelagem conceitual, lógica e relacional.
- Normalização de bancos de dados.
- Comandos e conceitos da linguagem SQL.
- Anotações e materiais de apoio das aulas.

Os materiais serão adicionados conforme o desenvolvimento da disciplina.
