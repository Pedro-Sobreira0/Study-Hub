Organizar os principais conceitos estudados, facilitando a revisão dos conteúdos e o acompanhamento do aprendizado.

## Conteúdo

- Resumos dos conteúdos das disciplinas.
- Anotações das aulas.
- Materiais de apoio e referências de estudo.

Os materiais serão adicionados conforme o desenvolvimento do módulo.
