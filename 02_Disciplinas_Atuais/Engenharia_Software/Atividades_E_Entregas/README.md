# Atividades e Entregas — Engenharia de Software

Esta pasta reúne as atividades e os trabalhos desenvolvidos na disciplina de Engenharia de Software.

## Objetivo

Organizar as entregas relacionadas aos conceitos, métodos e práticas estudados durante a disciplina.

- Exercícios e atividades da disciplina.
- Trabalhos individuais ou em grupo.
- Projetos e aplicações dos conceitos de Engenharia de Software.

Os materiais serão adicionados conforme o desenvolvimento da disciplina.
