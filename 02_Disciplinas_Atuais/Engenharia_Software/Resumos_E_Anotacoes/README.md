# Resumos e Anotações — Engenharia de Software

Esta pasta reúne os resumos, as anotações e os materiais de estudo da disciplina de Engenharia de Software.

## Objetivo

Registrar e organizar os conceitos relacionados ao desenvolvimento, à organização e à manutenção de sistemas de software.

## Conteúdo

- Ciclo de vida do software.
- Metodologias ágeis e requisitos de software.
- Conceitos de testes e qualidade de software.
- Anotações e materiais de apoio das aulas.

Os materiais serão adicionados conforme o desenvolvimento da disciplina.
