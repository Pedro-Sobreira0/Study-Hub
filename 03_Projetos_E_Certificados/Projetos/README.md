# Projetos

Esta pasta reúne os projetos desenvolvidos durante minha trajetória acadêmica em Engenharia de Software no CEUB e outros projetos pessoais relacionados à tecnologia.

## Objetivo

Organizar e documentar os projetos, registrando seu propósito, as tecnologias utilizadas e o aprendizado adquirido durante o desenvolvimento.

## Conteúdo

- Projetos acadêmicos.
- Projetos pessoais de programação.
- Protótipos e aplicações desenvolvidos durante o curso.
- Documentação e arquivos relacionados aos projetos.

Os projetos serão adicionados conforme forem desenvolvidos.
