Sobre a disciplina

Esta página reúne conteúdos e exercícios relacionados à construção de algoritmos e ao desenvolvimento do raciocínio lógico aplicado à programação.

O objetivo é documentar o aprendizado e organizar exemplos e atividades desenvolvidos durante o curso.

Conteúdos estudados

Variáveis e tipos de dados

Utilização de variáveis para armazenar informações, considerando tipos como inteiro, real e caractere.

Estruturas condicionais

Utilização de condições para executar diferentes instruções conforme os valores analisados. 

se (nota >= 7) {
    escreva("Aprovado")
} senao {
    escreva("Não aprovado")
}

Exemplo ilustrativo de uma estrutura condicional em Portugol.

Estruturas de repetição

Uso de laços de repetição para executar instruções várias vezes, de acordo com uma condição.

Exercícios práticos

Espaço destinado a exercícios de algoritmos, cálculos, comparação de valores e repetição, conforme o conteúdo desenvolvido em aula.
