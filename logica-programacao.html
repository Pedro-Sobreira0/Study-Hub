Lógica de Programação

Aprender a quebrar um problema em passos que o computador consegue seguir. Começo pelo Portugol, que deixa ver a sequência das instruções antes de usar uma linguagem de verdade.

Variáveis e tipos de dados

Variáveis guardam informações. Os tipos mais comuns são inteiro, real e caractere.

Estruturas condicionais

Uma condição decide qual instrução executar. Exemplo em Portugol:

se (nota >= 7) {
    escreva("Aprovado")
} senao {
    escreva("Não aprovado")
}

Estruturas de repetição

Os laços repetem instruções enquanto uma condição for verdadeira.
